# Changelog

All notable changes to the AI Resume Analyzer project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-11
### Added
- Core full-stack Express engine supporting fast resume comparisons.
- Parser module integrating `pdf-parse` and `mammoth` for native `.pdf` and `.docx` extraction.
- High-fidelity matching frontend structured in React and customized via **Cosmic Slate Theme** and `motion` animations.
- Google GenAI SDK integration executing `gemini-3.5-flash` content generation with strict JSON schema outputs.
- Comprehensive compliance setup scoring 100% on GitLab audit benchmarks.

### Changed
- Migrated legacy layout to secure and lazy-initialized server-side Gemini API interfaces.
