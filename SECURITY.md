# Security Policy

## Supported Versions

We actively update and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take cybersecurity and data privacy very seriously. If you identify a security issue or vulnerability with our ATS parser, please do not disclose it publicly or open a public issue.

Instead, please report it via one of the following channels:
1. Email your report to: `security@example.com`
2. Open a confidential incident ticket in research portals.

Please include:
- A clear description of the vulnerability.
- Minimal steps or scripts to reproduce the issue.
- Impact evaluation.

We will acknowledge receipt within 48 hours and coordinate a remediating patch within 7 days. Thank you for your support and collaboration in maintaining a safe, secure workspace!
